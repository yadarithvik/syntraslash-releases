# Syntra Slash desktop source

Created by **Rithvikyada**.

[Official website and download](https://syntraslash.pages.dev/#get-syntra) · [Project overview](../README.md) · [Development guide](../docs/DEVELOPMENT.md)

This directory contains the Windows application source associated with the v1.1.0 build. Start at `app.py`. First-run setup downloads or imports the model, verifies it, starts the local engine, and opens the workspace.

Model weights and engine binaries are external runtime dependencies. See the development guide before running or packaging the source.
