# Generative Ui

Create a self-contained HTML/CSS/JavaScript artifact using write_file in the selected workspace. Use native controls, labels, readable contrast, keyboard focus and responsive layout. Prefer local assets and explicit user inputs. Do not insert private data into remote scripts or services. Verify the generated file and JavaScript using existing tools; register_artifact links the result. Open the local HTML with open_path when requested. Syntra does not provide an inline privileged widget runtime; deliver an actual HTML artifact without claiming a nonexistent host render tool.
