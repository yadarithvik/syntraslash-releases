# Syntra Customizations

Use list_skills to inspect installed guidance. Use manage_extensions to discover local skills, import a selected catalog ID, enable or disable an installed skill, or import a local plugin folder when requested. The Skills, plugins & MCP panel exposes the same controls. Built-in guidance is included; imported instruction bundles start disabled. Configure local MCP commands in the MCP panel, connect the selected server, and discover its tools before use. Installing instructions does not add external tools or authentication. Do not edit another app’s configuration or import credentials implicitly.
