09 / A FEW THINGS TO KNOWTHE DETAILS
What is new in Syntra 1.2.0?＋

Twelve enabled built-in skills, PDF and image text readers, local skill imports, plugin bundles, the MCP manager with REA 6.8.0, and persistent one-shot local tasks. Syntra also keeps local strings, dossiers, and its compact work log.

Does local strings memory mean unlimited context?＋

No. Conversation history is stored separately from the model’s active input. Syntra retrieves selected excerpts instead of replaying the full chat. Its current model context remains bounded, recall can miss relevant details, and original history is retained locally.

Does Syntra run in this website?＋

This is the Syntra launch website with an illustrative interface preview. The AI model and desktop tools run in the Windows application.

Can I use Syntra offline?＋

After the initial model download, local AI tasks run without a cloud connection. Web browsing and other network tasks still need internet access.

What is included in the Windows package?＋

The installer includes Syntra, the local inference engine, and Python. On first launch, download Syntra Max Aperion (8.99 GB) with progress and pause/resume controls. The app verifies the model and connects it automatically. Existing users can import their matching model file.

What are Background and Transparent modes?＋

Background mode works with commands and files in your workspace. Transparent mode interacts with Windows applications using desktop controls. Desktop tasks act with your Windows account’s permissions; review the work and use Stop or Escape when needed.
